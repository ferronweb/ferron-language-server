# Ferron language server changelog

## `ferron-language-server` 0.1.2

**Released in September 15, 2026**

- The language server now updates Ferron to the latest version when available.
- Updated `ferron.conf` parser to the latest version with bugfixes.

## `ferron-language-server` 0.1.1

**Released in July 29, 2026**

- Changed the default Ferron download directory to use `ferron-language-server` instead of `.ferron-language-server-dl`.
- Fixed executable permissions not being set correctly on Unix.
- Fixed on-save hook checking files that aren't `ferron.conf`.
- Fixed on-save hook not working with Zed, due to strict capability handling.

## `ferron-language-server` 0.1.0

**Released in July 28, 2026**

- First release
